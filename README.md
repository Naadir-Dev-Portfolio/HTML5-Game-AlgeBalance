# Algebraverse

An endless, tiered algebra training game with built-in hints, a scratch-pad calculator, and a subtle animated background.

## Description

Algebraverse turns abstract equations into a playful journey. Solve problem after problem—linear equations, systems, rational expressions, absolute-value inequalities and more—at your own pace. Earn XP and 💰 coins, use hints and a built-in calculator, and see how far you can climb before your lives run out.

## Features

- **Endless Problems**  
  New questions auto-generated by difficulty tier (every 10 problems levels up).
- **Tiered Hints**  
  Three levels of step-by-step guidance—taking hints reduces your XP reward.
- **Scratch-Pad Calculator**  
  Evaluate or simplify expressions in-game, then insert results directly into answer fields.
- **Gamification**  
  XP, 💰 coins, lives, streaks and instant feedback to keep you engaged.
- **Dark Mode & Responsive**  
  Works on phones and desktop, adapts to any screen, dark mode by default.
- **Animated Background**  
  Subtle, relaxing bubble animation via Canvas 2D.

## Tech Stack

- **HTML5 & CSS3** (flex, grid, custom properties, animations)  
- **Vanilla JavaScript (ES6+)** – no frameworks or build tools  
- **[math.js](https://mathjs.org/)** – CAS for parsing, evaluating & simplifying expressions  
- **Canvas 2D** – animated background bubbles  
- **LocalStorage** – persist XP, coins, theme & lives between sessions  
- **Google Font: Manrope** – clean, accessible typography

## Installation & Usage

1. **Clone or download** this repository.  
2. Open **`index.html`** in any modern browser (Chrome, Firefox, Edge, Safari).  
3. Start solving—no build step or server required.

## How to Play

1. Read the problem at the top.  
2. Type your answer(s) into the input field(s).  
3. Click **Check** to submit.  
4. Use **Hint** for step guidance (costs some XP).  
5. Use the **Scratch-Pad** calculator as needed, then tap ⇢ to insert.  
6. Earn coins and XP for correct solutions; lose a life for mistakes.  
7. Game over when you run out of lives—reload to try again!
